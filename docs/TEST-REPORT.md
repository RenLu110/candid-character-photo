# v0.1.0 测试报告

日期：2026-09-11。v0.1.0采用经过rc2修订与复测的版本，用户已确认继续发布。rc1的通过结论不代表其审美已经被用户接受。

## rc2：增加远景与距离感

用户认为初版景别偏单一、偷拍感不够。复查发现，原验收偏重人物一致性和可读性，未检查人物在画幅中的大小；仅写“全身／长焦”仍容易生成占满画面的人像。

修订：默认有距离的日常观察；远景人物高度约20%–35%、中远景约35%–55%；参考只用于人物和服装，不继承近景构图。三张默认远／中远／中各一张，五张以上至少三分之一远景；明确全近景／全远景要求覆盖默认。新增隔街、商场高处和公园远景配方，质量检查不因远景脸部细节较少而自动推近。

| 新测试 | 方式 | 结果 |
|---|---|---|
| 隔街远景 | 主代理用真人参考探索规则 | 人物高度目测约28%；车顶、骑车人、道路和店门构成多层空间。 |
| 商场高处远景 | 主代理探索 | 人物目测约19%，比设计目标更小；建筑与人群主导，斜向扶手明确观察位置。 |
| 公园远景 | 主代理探索 | 坐姿人物目测约21%，枝叶／步道／长椅层次明确；实际偏阅读而非合书瞬间。 |
| 原创女性公园远景 | 新独立代理只读修订Skill与首张人物参考 | 人物高度目测约23%；衣服、发型连贯，三层空间成立；远景侧脸的细微五官难以充分核验。可用但有保留。 |

新增4张均各调用1次，没有重试或视觉修正；累计12张完成并查看。前三张是规则探索，不计修订版独立执行；最后一张才验证修改后的Skill。[公开远景样例与提示词](../examples/README.md)。真人远景仍只保留在本地，不公开。

独立策划复测（未额外生成图片）：默认3张实际分配远1／中远1／中1；默认5张远2／中远2／中1；用户指定全近景3张则近3，均保留动作和观察机制变化。

rc2主入口SHA-256：`d475ab42877aba18e34c2b6b763ee53e4d81486cc57abdfc6e7d75deee671902`。修订后重新进行ZIP隔离解压与逐文件校验；该版独立生图直接读取源码Skill，初版的隔离运行记录保留在下面，不混称为新版全局安装验证。全部占比均为目测，不是精密测量或模型硬参数。

完成8张真实生图：首轮真人参考3张、原创人物3张、角色名1张，以及修订后隔离副本的新场景1张。逐张看图后均可用于本次核心请求，存在下表所列保留项，没有通过反复挑图隐藏失败结果。首轮达到预设“7张至少6张可用”的候选验收门槛；这不是模型的总体成功率声明，也不等于8张完全无瑕疵。

另完成6个独立行为模拟案例，发现6处文档歧义并修正；复测原案例与两条3次调用预算轨迹通过。行为模拟不等于真实服务故障注入。

测试目标为当前 Codex 内置 image_gen。工具未暴露模型名称、种子或可用于复现的确定性焦段参数。

## 行为发现与修正

| 发现 | 修正 | 复测证据 |
|---|---|---|
| 无工具退路藏在条件引用内 | 主入口直接检查并说明无生图工具时的处理 | 缺工具案例明确无法出图，不伪造文件，不安装或切换付费服务 |
| 仅提示词批量依赖“先生成首图” | 明确文字模式重复固定人设，不生成首图 | n=2原案及n=3补充均只交付文字 |
| 技术重试与视觉修正预算歧义 | 整张共享一次技术重试，总调用≤3；确定性拒绝不盲重试 | 两条不同顺序轨迹都止于3次，保留已有图 |
| n=2误用n≥3组图门槛 | 质量表增加数量条件 | 两张不因未覆盖第二景别而自动重抽 |
| 陌生角色识别与成人演绎混杂 | 先核实角色，再决定成人演绎；冲突时问必要问题 | 未知角色不编造外观、不擅自生成 |
| 跨会话记录入口不明 | 固定记录文件名与当前任务查找范围，外部图不可用就待重附 | 无历史图片时请求重附，不扫描无关项目或假装记得 |

其他原案：不同人物参考先询问主体；批量第三张首次失败时保留前两张、仅补失败项。以上均为独立代理的响应与动作模拟，没有制造真实权限／额度故障。
