# 偶遇抓拍

把用户的人物放进一个可信、好看的日常瞬间。默认审美是「有距离的日常观察」：人物可辨、环境充分，观察位置受限，动作尚未结束。避免把所有图片做成加了模糊边框的精致人像。偷拍感来自距离、空间关系和时机，不依赖性化角度或糟糕画质。

## 输入与默认选择

- 照片输入：先看图，区分人物、服装、构图／风格参考。记录脸型、眉眼、鼻唇、发型、体态及用户要求保留的特征，不猜身份。两张同人物照片共同辅助相貌；明显不同人物且未指定主体时，只问一次使用哪位，不能擅自混脸。
- 角色名：先确认角色，再保留确定的识别特征，默认成年真人 COS。陌生角色先核实作品名或参考图，不编造原作外观。已确认成年角色直接设计。需要成人改编时采用明确成人外观、完整着装的非性化演绎，不靠一句“成年”保留明显幼态；用户要求与成人演绎冲突时询问一个必要问题。
- 描述输入：创建明确成年的原创人物。图片模式的批量任务先生成第一张并检查，以其人物形象辅助后续图片。仅提示词模式不生成首图，改为在每条提示词重复同一固定人设，并说明后续实际出图可引用合格首图。
- 默认 n=1、3:4 竖图、真人摄影、完整着装、公共日常场景。同组沿用人物和服装；用户指定优先于所有默认值。
- 用户只说“随机三张”就完成选择，不要求填写问卷。缺人物信息且上下文也没有人物时，询问人物来源。
- 用户只要提示词：输出逐张完整提示词，不调用生图。否则以真实图片为交付物，仅有文字不算生图完成。图片任务先检查工具能力；无生图工具就明确说明当前无法出图，可提供文字替代但不能声称完成，不擅自安装或切换付费服务。
- 只使用虚构／摆拍的公共空间模拟效果。不要生成私密空间偷窥、裙底视角或帮助真实非自愿跟踪。适用规则仍以当前宿主与生图工具为准。

## 设计画面

阅读 [场景配方](references/scene-recipes.md)，选与人物、服装、用户偏好相容的组合，再具体化。不要随机拼接互不相容的摄影术语。

每张先内部决定：

`场景｜动作瞬间｜身体朝向与视线｜观察者位置和距离｜遮挡物及位置｜景别＋人物高度占画幅比例｜成像方式｜光线｜轻微瑕疵`

1. 每张只有一个确定的主要动作、场景和主机位。最终提示词没有“喝水或翻书”“35–200mm 自动选择”等未决列表。静态图片写成动作瞬间，例如“指尖仍压着书页，头已转向镜头”。
2. 写清楚人物与摄影者的位置关系。遮挡物属于环境，贴近镜头的物体通常模糊；脸不能被关键遮挡破坏。约 15%–35% 的遮挡仅是起点，不必每张相同。
3. 手机风格采用较宽视角、更多环境、较深景深与自动曝光感；不要同时要求极强长焦压缩和超广角透视。隔玻璃明确是“透过玻璃看人”还是“看到反射中的人”，避免双脸。
4. 用自然重心、手部任务和视线表现日常。只选 1–2 种轻微不完美，面部与动作可读性优先。避免标准时尚摆拍、均匀磨皮、过度 HDR、强棚灯。
5. 少量图片可看向镜头。三张组图最多安排一张，十张约两张；没有硬性要求每组都“被发现”。用户指定优先。

### 距离与景别

“全身”不等于远景，“200mm”也不保证距离感。先确定人物在整张图里的占比，再安排合理机位与焦段。以下是视觉目标，不是精确模型参数：

| 景别 | 人物可见头至脚的高度占画幅 | 用法 |
|---|---|---|
| 环境远景 | 约20%–35% | 人物在街道、商场或公园中较小，环境主导 |
| 环境中远景 | 约35%–55% | 保留人物动作，同时看清人与环境的位置 |
| 人物中景 | 半身或人物高度明显超过55% | 作为组图节奏变化，不能独占默认组图 |

坐姿以坐姿人物的头至鞋外接高度估计，不把画幅面积与身高比例混用。单张未指定景别时优先环境中远景；用户强调“远景／偷感更重”时优先20%–35%远景，并按场景允许略小。

远景提示词明确：参考图只用于脸和衣服、不继承近景构图；人物小、全身处于大环境中、不要为了显示脸而推近。远处脸部信息自然减少，检查可见五官、发型、体态与衣服，不因缺少毛孔细节自动改成近景。

用至少三层空间：附近车顶／扶手／枝叶，间隔道路／中庭／空地，远处人物与环境。遮挡应显示摄影者所在位置，路人、车辆或建筑可部分遮住非关键身体部位。不必把人物两侧清场、专门打光，也不要把所有背景虚成光斑。

## 多张与连续使用

- 先安排整组，再逐张生图。默认三张包含一张远景、一张中远景及一张中景；五张以上至少三分之一安排远景（向上取整），其余变化分配。用户指定全近景或全远景时遵循用户，不强行混入其他景别。三张以上仍至少覆盖两种观察机制和两种动作，避免“左黑右人”。随机变化保留人物与造型。
- 同一组优先重复使用原始人物参考。原创人物第一张检查合格后作为后续身份参考，明确“沿用脸和服装，换动作、背景与构图”。不要只靠逐代图片接力，以免身份漂移。
- “再来三张”只读取当前会话、用户明确引用的记录，或当前任务交付目录的 `candid-generation-record*.md`，不扫描无关项目。避开有记录的最近配方；人物参考缺失时请重新提供，不能宣称仍精确保持相貌，也不能宣称避开没有记录的历史构图。
- n 张指 n 个独立图片文件。除非用户要求，不用一张拼图代替，也不在图片上自动印机位说明。

## 生成、检查与交付

图片任务按 [生图执行](references/generation.md) 检查能力并运行。不要把本 Skill 当作自带模型、免费额度或 API 密钥。所有上传、转交第三方和计费遵循用户已授权的工具范围。

检查每张真实成图：人物辨识度、造型、动作、观察位置、面部清晰度、手／道具／反射、同组差异和用户指定项。使用 [质量与修正](references/quality.md)。每张最多初次生成＋一次技术重试＋一次视觉修正，合计最多3次调用；确定性的权限、政策或额度拒绝不盲重试。保留已成功图片，超限后报告现状。

将最终图片存入用户指定位置或当前任务交付目录，使用不覆盖已有文件的名字。每组保存 `candid-generation-record-日期-组号.md`：用户请求、人物参考用途、整组设计、实际提示词、文件位置、工具、质量问题与调用次数。任务内文件用相对路径；外部只读参考可在私有记录中保留可解析引用，或标注“外部参考，下轮需重附”，不为满足路径要求复制进公开目录。模型或种子无法得知时写“工具未提供”。

展示图片并提供可点击原图位置。简短说明场景差异，不把内部策划全部贴进聊天。参考照片和生成图不能被描述为真实事件的取证图片。
