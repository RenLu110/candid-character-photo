# 看图与定向修正

看实际成图，不能只读提示词给出“通过”。这些是观察标准，不是人脸识别测量或统计保证。

| 维度 | 可用 | 需要修正 |
|---|---|---|
| 人物 | 关键脸型、眉眼、鼻唇、发型相符 | 明显换人、幼态化、组图换脸 |
| 指定内容 | 用户指定造型、地点、动作被遵循 | 擅自改变人物、服装或输出数量 |
| 动作 | 重心、手部任务、视线形成中间态 | 无任务的刻意正面摆拍 |
| 观察位置 | 能解释摄影者隔着什么、从哪里看 | 无法解释的黑条 |
| 可读性 | 在相应景别下人物和动作可辨，前景增强纵深；远景不要求毛孔级五官 | 主体完全不可辨、严重失焦或噪点；为了清晰而把远景推成近景 |
| 物理逻辑 | 手与道具合理，反射不复制人物 | 多指、道具连接异常、反射多脸 |
| 距离与组图 | 默认3张有远、中远、中景；5张以上至少三分之一远景；用户明确指定景别可覆盖默认 | 把占满画幅的全身照叫远景；未按请求安排远景，或同构图换背景 |

每张用“可用／可用但有保留／需修正”评价，并留一行具体证据。细小背景文字不一定阻断使用，但错误文字不能当作真实地点信息。

定向修正：不像参考时重附原图、强化五官；远景不要以放大人物代替身份保持。太像摆拍时写清动作中间态；遮挡呆板时改成下沿扶手、人群或树叶；玻璃混乱时明确透射或反射；批量重复时换观察机制和景别。请求远景却出成大人像时，优先把人物高度调到约25%，扩大可见环境，并明确不继承参考图构图。

不为一般性美化无限重抽。每张最多一次视觉修正，仍存在的问题如实报告。
