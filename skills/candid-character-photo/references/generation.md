# 生图执行

## 验证目标：Codex 内置 image_gen

按当前宿主工具说明发现并调用内置生图工具；可能暴露为 `image_gen.imagegen` 或编排器中的对应名称，不硬编码桥接层。它不是本仓库提供的工具。

1. 查看参考图片，再按用途列入提示词。全部参考有可读本地路径时，用工具支持的本地参考参数；只有会话图片时，按工具要求使用最近图片方式并限制数量。两种方式不能同时传，跨会话不假设还保留参考图。
2. 一张一个调用，批量每张独立构图。提示词明确：输入图片角色、唯一人物、造型、动作、摄影者位置、遮挡、成像、光线、比例、不需要文字／水印／拼图。
3. 新人物批量先完成第一张的身份与视觉检查，再以合格图片加固定人设指导后续；真人批量优先原始参考，不复制背景、水印或其他人。
4. 遵循工具的长任务与等待协议，确认调用最终完成。仅报告开始或仍在运行不算成功，用户应得到适当进度信息。
5. 查看成图。工具已显示图片时无需重复展示同一图。最终文件复制到交付目录，不删除原始工具输出，不覆盖旧图。
6. 参考读入失败先确认路径与可解码性。损坏编码可在工作目录做一次格式规范化，保留源图；不要偷偷去掉人物参考后继续出图。仍无法接收参考就说明失败原因。

## 失败与能力边界

- 每张图片总预算最多3次工具调用：初次生成1次，整张累计技术重试至多1次，视觉修正至多1次。技术重试预算在初次生成和修正阶段共享，修正失败不获得新额度。
- 临时工具错误可用剩余技术重试；权限、政策、额度等确定性拒绝不盲重试，不改变目的规避拒绝。成功图立即记入清单，仅补失败图。
- 例：初次失败→重试成功→视觉修正失败，共3次，停止并保留重试所得图片；初次成功→修正失败→技术重试成功，同样共3次。轮询已运行调用不算新生图，但中断后应先查已有结果，避免重复。
- 没有质量问题不消耗视觉修正。达到上限即交付现状和问题，不重跑整组。
- 没有可用生图工具：明确“当前无法生成图片”，可提供完整提示词；不得声称图片完成。不要未经请求安装插件、寻找密钥、切换付费 API 或借用其他产品当前项目。
- 其他生图模型尚无实测保证。用户明确选择时使用真实接口，不伪造参数，并说明未验证。
- 焦段仅为视觉指导，不能报告为真实拍摄 EXIF 或确定性模型参数。
